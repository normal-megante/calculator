# 電卓

スマホ向けの、誤差の出にくい電卓です。ブラウザで開いて、ホーム画面に追加するとアプリのように使えます。

- 数を分数のまま計算するので、0.1＋0.2 や 1÷3×3 もぴったり（0.3、1）になります。
- 約10万桁までの数を正確に扱えます。それより大きい数は「×10の〇乗」の形で出します。
- ＝ を押さなくても答えが出ます。式の途中をタップして直せます。
- 計算の履歴に名前と種類を付けて、あとから探したり、ほかの式に使ったりできます。
- データはすべて、使っているスマホのブラウザの中にだけ保存されます。

## 開発

- サーバー：`python dev-server.py` → http://localhost:8150
- テスト：`node --test`
