              1円未満の端数

              この電卓について

              誤差を出さないしくみ

              数を「分数のまま」持って計算するので、たし算・ひき算・かけ算・わり算は誤差ゼロです（1÷3×3 ＝ ぴったり 1）。約10万桁までの数を正確に持てます。

              √ のように割り切れない計算は、80桁で計算して上から50桁を出します。それより大きな数は「×10の〇乗」の形になります（10 の 1000兆乗 まで）。

              計算のきまり

              • × ÷ を先に、＋ − をあとで計算します。( ) の中が先です。
              • 2(3+4) や 2√3 のように、× を省いてもかけ算になります。
              • −2² は −4（2乗が先）、2^3^2 は 2^9 です。
              • % は「100で割る」です。ただし ＋ − の後ろの % は「左の数の〇%」です（200＋10% ＝ 220）。
              • 閉じていない ( は、＝ を押すと最後に閉じます。

              式の途中を直す

              式をタップすると、そこにカーソルが入ります。◀ ▶ で1つずつ動かせます。⌫ はカーソルの左を消し、数字はカーソルのところに入ります。

              検算

              ＝ のあとの「✓ 検算」（履歴からも使えます）で、2つの方法で確かめられます。

              • 逆算：計算した順番に1つずつ、逆の計算で元の数にもどるかを見せます（1,280×3＝3,840 → 3,840÷3＝1,280 ✓）。
              • 照合：同じ計算をもう一度打つと、1回目とちがう数字・抜けた数字を赤で知らせます。打ちまちがいを見つけるのに使います。

              お買い物

              • 合計を出す：値段・個数・税率（10%／8%）・割引を入れて足していくと、税込の合計が出ます。予算を入れると残りも出ます。
              • 税込・税抜：値段を1つ打つと、10% と 8% の税込・税抜がすぐ出ます。
              • 消費税は、レシートと同じく「税率ごとにまとめて」計算し、1円未満は切り捨てます（⋯ から変えられます）。

              割り勘

              • 払う合計と人数を打つと、1人あたりが出ます。
              • 「人の組を足す」で、組ごとに「〇倍」「〇円足す・引く」「1人〇円だけ（金額指定）」にできます。
              • 「一部の人だけで払う物」で、お酒などを、えらんだ人だけで等分できます。
              • 端数は、何円単位で、切り上げ・切り捨て・幹事が合わせる、からえらべます（⋯）。

              時間

              • 時間の計算：数を打って「時間」「分」などを押すと、60進法のまま計算します（1時間30分 ＋ 45分 ＝ 2時間15分）。「9:30」のように「:」でも打てます。
              • 時間 × 数、時間 ÷ 数、時間 ÷ 時間（何回分）もできます。時間 ＋ 数 のように単位がそろわない計算はできません。
              • ＝ を押すと、履歴に種類「時間」で残ります。電卓で使うときは「時間の数」（2時間15分 → 2.25）になります。
              • 時給：時給と、始め・終わり・休憩（または働いた時間）を打つと、給料が出ます。えらべば、深夜・残業の割増も入ります。

              日付

              • 日数：始めと終わりの日付で、間の日数が出ます（始めの日も数えた「〇日間」も）。平日・土日・祝日の数も出ます。
              • 〇日後：日付から〇日・〇週・〇か月・〇年あと（前）の日付が出ます。1/31 の1か月後のように、ない日になるときは月末（2/28）に合わせます。土日・祝日をとばす（営業日）もできます。
              • 年齢・和暦：生年月日から満年齢・和暦・干支・次の誕生日まで、が出ます。
              • 日付は「2026/11/9」のように「/」で区切って打ちます。「和暦」キーで 令和・平成・昭和 の年でも打てます。空の欄は「今日」です。
              • 祝日は 2000〜2099年の分を、祝日の法律のきまりから計算しています（法律が変わると、ずれることがあります）。会社の休みや年末年始は入っていません。
